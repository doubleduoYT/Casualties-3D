# Art, audio, code, and intellectual property policy

This is an **unofficial, non-commercial** fan project. Non-commercial intent does **not** automatically grant permission to copy or redistribute someone else's creative work.

## What contributors may submit

- Work that they created and are authorized to contribute, **after** the team agrees on how it may be used and redistributed.
- Materials under compatible third-party licenses, with a copy/link to the license and required attributions; have the team verify compatibility before committing.
- Placeholder or prototype assets that are safe to distribute with the repository.

## What not to submit without specific permission

- Extracted models, textures, animations, maps, scripts, sound effects, music, fonts, or builds from the original game.
- Any other fan project's code or assets unless its terms clearly permit the intended reuse.
- Paid marketplace assets unless their license permits this form of public source distribution.
- Leaked files, proprietary third-party code, personal data, API keys, passwords, or tokens.

## Asset provenance

For each new non-trivial art, music, or third-party code contribution, record:

| Field | Example |
| --- | --- |
| Asset path | `Assets/Art/Characters/Placeholder.fbx` |
| Creator/source | Contributor handle or original URL |
| Permission/license | Explicit written permission or license name/link |
| Attribution | Credit line requested by creator |
| Distribution allowed? | Yes / No / Pending |

Keep this information in the related PR and, when added, in an asset credit manifest. If permission is pending, **do not push the file** to a public repo.

## Licensing status

No code or content license has been selected for this repository. The public repo setting alone does not grant usage or redistribution rights. The team should agree on license terms with contributors and obtain any needed third-party/original-game permissions *before* publicly distributing a build or adding protected content.

This document is a project guideline, not legal advice.
